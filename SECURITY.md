# Security Policy

## Supported version

The active security target is the `features/wails3` branch and its latest published commit. The archived `features/tauri` baseline is retained for reference and is not the active development target.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through [GitHub Security Advisories](https://github.com/MorenoLand/Moreno.YTLite/security/advisories/new). Include the affected commit or release, operating system, reproduction steps, impact, and any relevant logs with secrets removed.

Do not open a public issue, publish an exploit, or send credentials, cookies, updater keys, or private application data in a report.

## Scope

Reports involving the native Wails3 bridge, the embedded player guard, local data handling, Windows input locking, release automation, or dependency vulnerabilities are in scope. YouTube availability and changes to public YouTube HTML are service-compatibility issues unless they create a separate security impact.
